# Huy hiệu mức

Mức thành thạo một dạng bài: **Mới bắt đầu → Đang tập → Khá → Tốt → Vững** (ngưỡng 0 · 40 · 60 · 75 · 85 % đúng, `HS_MUC` trong mã).

- **Màu** (giống hai theme, chỉ khác bo góc): Vững `-ok` trên `-ok-soft` · Tốt `px-sea-deep`/`lms-pri` trên `-pri-soft` · Khá `-warn` trên `-warn-soft` · Đang tập `orange-deep` trên `#FDE6DE` · Mới bắt đầu `app-ink` trên `mist`. Mỗi huy hiệu có ô màu nhỏ + chữ, nên người mù màu vẫn phân biệt được.
- **Pixel**: khung `frame-2` khuyết góc, góc vuông, chữ 12.5/600. **Classroom**: viên bo 16, chữ 13/500, chấm tròn.
- **Cỡ**: cao 28px — là nhãn, không phải nút; đặt cạnh tên dạng bài hoặc trong ô bảng.
- **Không**: đổi thứ tự hay tên mức; dùng làm nút lọc (dùng `jc-seg`).
