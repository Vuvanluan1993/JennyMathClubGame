Màn đăng nhập học sinh: nền `sky` chấm sóng, thẻ trắng khung khuyết góc + bóng cứng 8px, Jenny + tên app VT323 34, hai ô nhập, ghi nhớ, nút VÀO HỌC, dòng dặn. Ghép từ: Khung pixel (`frame-3`), Bảng nhập (ô nhập `jc-input`), Nút (`jc-gobtn`), Thẻ chào (ô nhân vật).

- Ô nhập cao 48, chữ 17, nền `app-surface-2`, khung `frame-2`; nút hiện mật khẩu 40×40 trong ô.
- Nút VÀO HỌC: nền `px-sea`, VT323 28 viết hoa, cao 54. Lỗi hiện dưới nút bằng chữ `px-coral` 600 ("Mật khẩu chưa đúng, em thử lại nhé.").
- Cổng GV/PH/QL dùng cùng thẻ này (nền `sky` phẳng, tiêu đề "Giáo viên", nút "Đăng nhập", mục "Xem bản demo").
