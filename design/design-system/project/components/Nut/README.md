# Nút

Nút là cách duy nhất để làm một việc; mỗi màn có **một** nút chính. Chữ là động từ ngắn: "Vào học", "Đưa vào lớp", "Phối đồ ▸".

- **Biến thể**: `pri` (chính, nền `px-sea`/`lms-pri`, chữ trắng) · mặc định (phụ, nền trắng) · `danger` (nền `-bad-soft`, chữ `-bad`; Classroom viền hồng) · `ghost` (không viền, chữ phụ) · `sm` (nhỏ) · `.jc-gobtn` (VÀO HỌC / Đăng nhập: rộng hết, VT323 28 viết hoa ở Pixel, Lexend 17/600 ở Classroom).
- **Trạng thái**: thường · rê (`surface-2` / `#F4F8FC`) · bấm (Pixel lún 3px) · tiêu điểm (Pixel viền `px-sun` 3px, Classroom `lms-pri` 2px) · tắt (`opacity .45`, không bấm).
- **Cỡ chạm**: Pixel ≥ `size-tap` 48px, nhỏ 44px. Classroom 36/32px như mã hiện tại (đề xuất 44, chờ thầy). Rộng tối thiểu theo chữ + 16px mỗi bên.
- **Nên**: một nút `pri` mỗi khung; `danger` luôn hỏi lại bằng Hộp thoại. **Không**: hai nút chính cạnh nhau; chữ dài quá 3 từ; dùng nút cho liên kết.
