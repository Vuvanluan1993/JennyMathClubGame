# Tự luyện · Bảng dạng bài lớp 1 tập 1 (rà từ VBT tham khảo)

Nguồn tham khảo: Vở bài tập Toán 1 tập 1 (bộ Chân trời sáng tạo, 105 trang, bản scan của thầy).
Chỉ ghi **dạng bài** bằng lời của mình, không chép chữ, số, hình của sách. App bám Kết nối tri thức nên ghép theo **kiến thức**, không theo tiết.

Ký hiệu cột "App": ✓ đã có dạng tương tự trong đảo · ◐ có một phần · ✗ chưa có (cần làm mới cho Vở bài tập Jenny).

## 1. Hình, vị trí (ứng với KNTT chủ đề 2 và 4)
| Dạng bài | App |
|---|---|
| Tô/khoanh vật theo vị trí trái–phải, trên–dưới, ở giữa, trước–sau | ✓ |
| Tô hình theo loại (khối hộp chữ nhật, khối lập phương; tròn, vuông, tam giác, chữ nhật) | ✓ |
| Tìm hình trong một túi hình lẫn lộn | ✓ |
| Quy luật dãy hình, vẽ tiếp hình | ✓ |
| Vẽ lại hình trên lưới ô vuông / lưới chấm theo mẫu | ✗ (có màn Vẽ hình, có thể dùng) |
| Xếp hình ghép (kiểu tangram) ra con vật | ◐ |
| Tô màu tranh theo mã hình (tam giác màu A, tròn màu B…) | ✗ |
| Đếm khối, đếm hình trong một tranh ghép | ✓ |

## 2. Số đến 10 (ứng với KNTT chủ đề 1)
| Dạng bài | App |
|---|---|
| Đếm rồi viết số; khoanh nhóm đúng số | ✓ |
| Nối số với chấm tròn / ngón tay / khung 10 ô | ✓ |
| Dãy số có ô trống (xuôi, ngược) | ✓ |
| Bảng số nhỏ điền ô thiếu | ◐ |
| Tranh lớn nhiều con vật: đếm từng loại, ghi vào bảng | ✗ |
| Vẽ thêm chấm / tô thêm cho đủ số | ✓ |
| Thứ tự trái → phải: thứ hai, thứ năm, cuối cùng | ✓ |
| Xếp số từ bé đến lớn và ngược lại (có cả chiều ngược) | ✓ |
| Khoanh số lớn nhất / bé nhất | ✓ |
| Bằng nhau, nhiều hơn, ít hơn: nối cặp, gạch bớt, vẽ thêm cho bằng | ◐ |
| Điền >, <, = ; một ô trống nối tới nhiều số (ví dụ ☐ < 3) | ◐ |
| Đúng ghi Đ, sai ghi S nhiều ý | ◐ (có đúng/sai 1 ý) |

## 3. Tách – gộp số (sơ đồ ba vòng tròn)
| Dạng bài | App |
|---|---|
| Nhìn tranh, điền sơ đồ tách–gộp | ◐ |
| Nối sơ đồ với tranh | ✗ |
| Khoanh các cặp số tạo thành một số trong bảng số | ✗ |
| "Nhà số": mái ghi số, các tầng ghi cặp tách | ✗ |

## 4. Cộng, trừ trong 10 (ứng với KNTT chủ đề 3)
| Dạng bài | App |
|---|---|
| Nhìn tranh viết phép cộng / trừ (thêm vào, bớt đi, gộp hai nhóm) | ✓ |
| Tính nhẩm theo cột; tính 3 số | ✓ |
| Tìm số trong ô trống ở phép tính | ✓ |
| Từ một sơ đồ tách–gộp viết đủ 4 phép tính (cộng, trừ) | ✗ |
| Đếm thêm / đếm bớt bằng ngón tay, bảng đếm | ✓ (hướng dẫn hai bàn tay) |
| Nối phép tính với kết quả | ✓ |
| Tháp số (ô trên = tổng hai ô dưới) | ✗ |
| Lưới phép tính ngang–dọc điền số, điền dấu | ✗ |
| Tam giác số (tổng mỗi cạnh) | ✗ |
| Tô màu tranh theo kết quả phép tính | ✗ |
| Xếp phép tính theo kết quả từ bé đến lớn | ✗ |
| So sánh phép tính với phép tính (7+2 … 7+1) | ✓ |
| Bảng cộng, bảng trừ: điền phần thiếu, tô theo kết quả | ✓ |
| Đọc tranh, nói câu "Có … thêm … có tất cả …" rồi viết phép tính | ✓ |

## 5. Kiểm tra (cuối chương, cuối kì)
Trộn trắc nghiệm A/B/C, Đ/S, nối, tự luận ngắn → dùng làm **trang Ôn chương** trong Vở bài tập Jenny.

## Kết luận cho Vở bài tập Jenny
- Phần lớn dạng bài đã có trong đảo → trang vở **trộn lại** các dạng đó, số mới mỗi lần.
- Dạng mới đáng làm (vui, hợp lớp 1, dễ chấm trên máy): **Nhà số, Tháp số, Gia đình 4 phép tính, Lưới phép tính, Tam giác số, Tô màu theo kết quả, Đ/S nhiều ý.**
- Bỏ qua: tô màu tự do, xếp tangram thật, vẽ tranh tự do (khó chấm).
